# AGRIMAP
### Sistem Informasi Geografis Lahan Petani Berbasis Web

**AgriMap** merupakan sistem informasi geografis berbasis web yang dikembangkan untuk membantu pengelolaan data petani dan pemetaan lahan pertanian. Sistem ini memanfaatkan teknologi pemetaan digital untuk menyajikan informasi mengenai lokasi, luas, dan karakteristik lahan pertanian.

## Fitur Utama
- Pemetaan lokasi lahan pertanian.
- Visualisasi petak lahan petani.
- Pengelolaan data identitas petani.
- Informasi luas dan wilayah lahan.
- Integrasi data spasial menggunakan GeoJSON.

## Teknologi yang Digunakan
- HTML
- CSS
- JavaScript
- Leaflet.js
- GeoJSON
- GitHub Pages

## Tujuan Pengembangan
AgriMap dikembangkan sebagai sarana digital untuk mendukung pengelolaan informasi lahan pertanian, mempermudah visualisasi lokasi lahan, serta membantu penyajian data pertanian secara lebih terstruktur.
